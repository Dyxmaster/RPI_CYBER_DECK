# 🛰️ RPI_CYBER_DECK

> 面向 Raspberry Pi 等 ARM 边缘硬件的轻量级边缘设备管理与控制平台

RPI_CYBER_DECK 是一个专为 **树莓派（Raspberry Pi）及 ARM 架构边缘设备**设计的轻量级设备管理平台。

项目致力于解决小型物联网设备、嵌入式实验环境以及边缘计算场景中的设备管理问题，通过**本地化部署、低资源占用、无需依赖公有云**的方式，实现边缘节点接入、运行状态监控、远程控制以及硬件扩展管理。

平台支持可配置 **AI 运维节点（AI Agent）**，能够结合设备运行数据进行状态分析、异常诊断、自动化任务调度与智能运维决策，进一步提升边缘设备的自主运行能力，构建低成本、高可靠、智能化的边缘计算管理体系。

相比传统云端 IoT 平台，RPI_CYBER_DECK 更关注 **本地自治、快速响应、低成本部署**，适合 DIY 物联网、小型边缘集群、智能硬件实验以及个人 Homelab 场景。

---

## ✨ 项目特点

### 轻量化边缘设计

针对 Raspberry Pi 等低功耗 ARM 设备进行优化：

- 低 CPU / 内存占用
- 无需高性能服务器支持
- 可直接运行于边缘节点本地
- 适合长期稳定运行

让普通开发板也能具备设备管理能力。

---

### 📡 边缘节点接入管理

支持多个 ARM 边缘设备统一接入：

- 节点注册与身份管理
- 在线状态检测
- 心跳保活机制
- 节点连接状态追踪
- 多设备集中管理

轻松构建个人边缘设备网络。

---

### 🎛️ 远程设备控制

通过 Web 控制台实现远程操作：

- 远程执行系统指令
- 控制 GPIO 外设
- 调用设备脚本
- 管理传感器与执行器
- 执行自定义控制任务

无需频繁 SSH 登录每一台设备。

---

### 📊 边缘状态监控

实时采集设备运行状态：

- CPU 使用率
- 内存占用
- 磁盘空间
- 网络状态
- 系统运行信息

帮助快速发现设备异常并进行维护。

---

### 🔌 面向 Raspberry Pi 生态

原生适配 Raspberry Pi 系列设备，并支持进一步扩展：

- GPIO 控制
- 传感器接入
- 继电器模块
- 摄像头设备
- 自动化执行组件

为 DIY 智能硬件项目提供基础管理能力。

---

### 🌐 本地 Web 管理控制台

提供浏览器端可视化管理界面：

- 设备列表展示
- 节点状态查看
- 控制指令发送
- 操作记录查询
- 运行状态监控

无需额外安装客户端。

---

### 📝 完善的操作日志

记录关键设备事件：

- 设备上线 / 离线
- 控制指令执行
- 系统操作记录
- 调试信息保存

方便问题定位与运行维护。
